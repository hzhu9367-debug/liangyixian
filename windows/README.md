# 桌面晾衣杆 Windows 测试版

适用 Windows 10/11 64 位（x64）。打开 Setup.exe 安装即可，不需要 GitHub 登录、Git、Node 或开发环境。所有数据保存在本机，不包含作者的私人便签和截图。

## 使用

- 左上角小锤子：新建文字便签。输入框支持 Ctrl+V 和换行。
- 图钉按钮：选择“始终显示”或“顶部悬停显示”。
- 相机按钮：框选截图。
- 把 PNG/JPG/WebP/BMP 图片拖到绳子上，或从任务栏托盘菜单导入图片、挂上剪贴板图片。
- 拖动便签可调整顺序；文字便签可拖出纯文字，图片的“拖出图片”按钮可把文件拖入其他应用。
- 悬停时显示复制、锁定、收起、回收站按钮。双击文字便签可编辑。
- 绳子满后进入待上绳区，不自动替换旧图。左上角叠放按钮管理待上绳与最近收起。
- 收起不删除文件。删除需确认，仅删除软件保存的副本，导入时的原文件保留。
- 收起、删除、替换可在 10 秒提示中撤销，或在管理窗口用 Ctrl+Z。撤销历史仅保留本次运行。
- 编辑窗口的调色盘按钮打开便签工坊：上传不超过 20 MB 的底图，拖动绿色区域调整文字区，右下角可缩放；点击底图调整夹子位置，保存后可在外形列表选用。
- 托盘菜单可以设置截图文件夹，或退出应用。默认监听“图片/Screenshots”，不会导入启动前已有文件。

## 已知限制

这是独立移植的首个 Windows 测试版，不是原生 Swift 程序。已在 Mac 上测试共享逻辑与 Electron 界面，并生成 Windows 安装程序，但尚未在真实 Windows 机器上验证安装、屏幕截图、多显示器和全屏游戏。独占全屏可能遮挡桌面浮层，可尝试无边框全屏。没有代码签名，系统可能显示未知发布者提示。

仅发布 x64 包，尚无原生 Windows ARM64 包。样式和文件不与 Mac 版自动同步。

## 开发

运行 `npm ci`，然后 `npm start`。测试用 `npm test`。安装包用 `npm run dist:win`，输出在 `dist/`。开发时不需要 GitHub 登录。
